# 🍽️ Swiggy Sales Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Swiggy Sales Analysis Dashboard** built using Microsoft Excel. The dashboard analyzes food delivery sales performance across different states, cities, restaurants, food categories, and time periods.

The objective of this project is to transform raw sales data into meaningful business insights using data analysis, visualization, and interactive dashboard reporting.

> **Note:** The dataset used in this project was collected from publicly available external/other resources and is used solely for data analysis and portfolio purposes.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Track monthly, daily, and weekly sales trends
- Compare sales across different states and cities
- Analyze food category performance
- Understand customer ratings and rating counts
- Identify top-performing cities and restaurants
- Track order volume and average order value
- Provide interactive filtering for better data exploration

---

## 📊 Key Performance Indicators (KPIs)

## 📈 Dashboard Features

### Sales Analysis
- Monthly Sales Trend
- Daily Sales Trend
- Weekly Sales Trend
- Quarterly Sales Analysis

### Geographic Analysis
- Sales by State
- Top 5 Cities by Sales

### Food Analysis
- Sales by Food Type
- Category-wise Analysis
- Dish-level Analysis

### Restaurant Analysis
- Restaurant-wise Sales Analysis
- Restaurant filtering and comparison

### Interactive Filters
The dashboard includes slicers for:

- Month
- Category
- Restaurant Name

These filters allow users to interactively explore the data and analyze specific business segments.
